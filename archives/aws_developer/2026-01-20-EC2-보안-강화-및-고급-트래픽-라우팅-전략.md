### EC2 인스턴스에 대한 네트워크 보안 강화 전략

- 현재 보안 설정의 문제점 진단
- 로드 밸런서를 통한 EC2 접근 강제화
    - EC2 보안 그룹 규칙 변경 단계
        - EC2 인스턴스의 보안 그룹 확인
        - 인바운드 규칙 편집
        - 기존 HTTP(S) 규칙 삭제
        - 새 규칙 추가
            - 유형(Type): HTTP/HTTPS
            - 소스(Source): Custom - 로드 밸런서의 보안 그룹

### Application Load Balancer(ALB)의 고급 리스너 규칙 활용

- 기본 규칙(Default Rule): 모든 요청에 대해 적용되는 최종 규칙입니다.
- 사용자 정의 규칙: 특정 조건이 만족될 때만 적용되는 규칙으로, 우선순위(Priority)를 가집니다.

#### 고급 리스너 규칙 설정 방법

- 경로(`Path`)
- 호스트 헤더(`Host header`)
- HTTP 메서드(`HTTP method`)
- 소스 IP(`Source IP`)
- 쿼리 문자열(`Query string`) 또는 HTTP 헤더(`HTTP header`)
