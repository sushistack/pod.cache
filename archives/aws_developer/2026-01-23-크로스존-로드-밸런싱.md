### 크로스존 로드 밸런싱이란?

크로스존 로드 밸런싱은 로드 밸런서 노드(Load Balancer Node)가 트래픽을 자신의 가용 영역 내 EC2 인스턴스에만 보내는 것이 아니라, 로드 밸런서에 등록된 **모든 가용 영역의 모든 EC2 인스턴스에 걸쳐 트래픽을 균등하게 분산**시키는 기능입니다.

### 로드 밸런서 유형별 크로스존 로드 밸런싱 동작 및 요금 정책

#### Classic Load Balancer (CLB)

- 기본적으로 비활성화(Disabled)
- 활성화하더라도 Inter-AZ 데이터 전송에 대한 요금이 부과되지 않음.

#### Application Load Balancer (ALB)

- 기본적으로 활성화(Enabled)
- Inter-AZ 데이터 전송(AZ 간 데이터 이동)에 대한 요금이 부과되지 않음.
- **타겟 그룹(Target Group) 수준에서 개별적으로 비활성화** 가능. 이는 특정 마이크로 서비스나 워크로드에 대해 AZ 내 로컬리티를 유지하고자 할 때 유용합니다.

#### Network Load Balancer (NLB) & Gateway Load Balancer (GLB)

- 기본적으로 비활성화(Disabled)
- 활성화하는 경우, Inter-AZ 데이터 전송에 대한 요금이 부과

### 크로스존 로드 밸런싱 활성화의 장점

- 균등한 부하 분산
- 간소화된 스케일링
- 향상된 탄력성

### 크로스존 로드 밸런싱 비활성화의 장점 (NLB/GLB에 해당)

- 데이터 로컬리티 유지
- 비용 통제
- 특정 아키텍처 요구사항
