## 2026-01-06 EC2 인스턴스를 위한 IAM 역할

<details>
<summary>복습 키워드: EC2 인스턴스를 위한 IAM 역할</summary>

### EC2 인스턴스를 위한 IAM 역할

- EC2 인스턴스에 AWS 리소스 접근 권한을 부여하는 가장 안전한 방법은 IAM 역할을 활용하는 것


### 🚨 AWS 자격 증명 직접 설정의 위험성

- `aws configure` 명령어를 사용하면 Access Key ID와 Secret Access Key, 리전 등을 직접 입력하여 자격 증명을 설정할 수 있습니다.
    - 하지만 이는 절대 해서는 안 되는 매우 위험한 방식입니다.

#### 심각한 보안 문제

- 자격 증명 노출 위험
- 권한 과다 부여
- 자격 증명 수명 주기 관리의 어려움

### 역할 권한 변경의 즉각적인 효과

- IAM 역할의 또 다른 장점은 권한 변경이 즉각적으로 반영된다는 것입니다. 인스턴스를 재부팅할 필요 없이, 역할에 연결된 정책만 수정하면 됩니다.
