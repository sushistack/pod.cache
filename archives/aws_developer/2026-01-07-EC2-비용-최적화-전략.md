### EC2 비용 최적화 전략

- On-demand instances: 가장 기본적인 EC2 구매 옵션으로, 인스턴스를 필요할 때 즉시 시작하고 사용한 만큼만 비용을 지불
- reserved instances: 1년 또는 3년 약정 기간 동안 특정 인스턴스 속성을 예약하여 온디맨드 요금 대비 상당한 할인을 제공
- Convertible reserved instances: 일반 예약 인스턴스보다 유연성이 높아 인스턴스 속성을 변경 가능
- Saving plans: 예약 인스턴스의 현대화된 버전으로, 특정 인스턴스 유형 대신 시간당 사용 금액에 대한 약정을 통해 할인을 제공
- Spot Instances: AWS가 여유 있는 EC2 용량을 매우 저렴한 가격에 제공하는 옵션
- Dedicated Hosts: 단일 테넌트(Single-tenant) 환경에서 실제 물리 서버를 완전히 예약하여 사용하는 옵션
- Dedicated Instances: 사용자 전용 하드웨어에서 실행되는 인스턴스
- Capacity Reservations: 특정 가용 영역(AZ)에서 온디맨드 인스턴스 용량을 원하는 기간 동안 예약하는 옵션


### EC2 인스턴스 구매 옵션 비교 요약

다음 표는 주요 EC2 구매 옵션의 특징을 간략하게 비교하여 보여줍니다.

| 구매 옵션 | 할인율 (온디맨드 대비) | 약정 기간 | 유연성 | 과금 방식 | 주요 사용 사례 |
| :---- | :--- | :--- | :--- | :--- | :--- |
| **온디맨드** | - | 없음 | 높음 | 초/시간 단위 | 단기, 예측 불가능한 워크로드 |
| **예약 인스턴스** | 최대 72% | 1년 또는 3년 | 낮음 (특정 인스턴스 속성 고정) | 약정 기간 동안 지불 | 안정적, 장기 운영 워크로드 (DB) |
| **컨버터블 RI** | 최대 66% | 1년 또는 3년 | 높음 (인스턴스 유형 등 변경 가능) | 약정 기간 동안 지불 | 장기 운영, 미래 인스턴스 변경 가능성 있는 워크로드 |
| **Savings Plans** | 최대 72% | 1년 또는 3년 | 높음 (사용량 USD 약정, 인스턴스 크기/OS 유연) | 약정 후 초과시 온디맨드 | 장기 사용량 예측 가능, 인스턴스 구성 유연성 필요 시 |
| **스팟 인스턴스** | 최대 90% | 없음 | 매우 높음 (언제든 회수 가능) | 입찰가 기반 | 실패에 탄력적인 배치 작업, 대규모 데이터 처리 |
| **전용 호스트**   | - (예약 시 최대 70%)   | 온디맨드/1-3년 | 낮음 (물리 서버 독점) | 초/시간 단위 | 규제 준수, BYOL, 물리적 격리 요구 사항 |
| **전용 인스턴스** | - | 없음 | 낮음 (하드웨어 격리) | 초/시간 단위 | 하드웨어 격리 요구 사항 (전용 호스트보다 덜 엄격) |
| **용량 예약** | - | 없음 | 높음 (기간 없이 예약) | 온디맨드 요율 | 특정 AZ에서 단기 인스턴스 가용성 보장 필요 시 |
