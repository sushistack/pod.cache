## 2026-01-05 EC2 인스턴스 타입 심층 분석


<details>
<summary>복습 키워드: EC2 인스턴스 타입</summary>

### EC2 인스턴스 타입의 구성 요소

*   **인스턴스 클래스 (Instance Class)**: `m`: 인스턴스 클래스는 컴퓨팅 성능을 나타냅니다.
*   **세대 (Generation)**: `5`: 인스턴스의 세대는 컴퓨팅 성능과 가격, 에너지 효율성 등을 나타냅니다.
*   **크기 (Size)**: `2xlarge`: 인스턴스 크기는 해당 클래스 및 세대 내에서 제공하는 컴퓨팅 자원(vCPU, 메모리)의 양을 나타냅니다.

```
m5.2xlarge
└─┘└─┘└─────┘
클래스  세대   크기
```

### 인스턴스 클래스

- T 시리즈 (`t2`, `t3`, `t4g` 등): 버스터블(Burstable) 성능을 제공하며, 단기간 동안 높은 CPU 성능을 요구하는 워크로드에 적합. 
- M 시리즈 (`m2`, `m3`, `m4`, `m5`, `m6g` 등): 일반적인 컴퓨팅 성능을 제공하며, 일반적인 워크로드에 적합.
- C 시리즈 (`c2`, `c3`, `c4`, `c5`, `c6g` 등): 컴퓨팅 성능을 최적화한 인스턴스로, CPU 성능이 높은 워크로드에 적합.
- R 시리즈 (`r2`, `r3`, `r4`, `r5`, `r6g` 등): 메모리 성능을 최적화한 인스턴스로, 메모리 사용량이 많은 워크로드에 적합.
- X1 시리즈 (`x1`, `x2`, `x3`, `x4`, `x5`): 고성능 컴퓨팅을 위한 인스턴스로, GPU가 내장된 인스턴스로, AI/ML, 데이터 분석 등에 적합.
- Z1d 시리즈 (`z1d`): 최고의 네트워크 성능을 제공하며, 네트워크 성능이 중요한 워크로드에 적합.
