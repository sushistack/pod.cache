## 2026-01-06 AWS 보안 그룹

<details>
<summary>복습 키워드: AWS 보안 그룹</summary>

### AWS 보안 그룹

* AWS 보안 그룹은 EC2 인스턴스 앞단의 가상 방화벽으로, 인바운드 및 아웃바운드 네트워크 트래픽을 제어합니다.
* 오직 '허용(Allow)' 규칙만으로 동작하며, IP 주소 범위 또는 다른 보안 그룹을 통해 트래픽 소스를 지정할 수 있습니다.
* 기본적으로 모든 인바운드 트래픽은 차단되고 모든 아웃바운드 트래픽은 허용되므로, 적절한 규칙 설정을 통해 보안을 강화해야 합니다.


### 보안 그룹의 주요 특성 및 고려 사항

- 다대다 관계: 하나의 보안 그룹은 여러 EC2 인스턴스에 연결될 수 있으며, 하나의 EC2 인스턴스 또한 여러 보안 그룹에 연결될 수 있음
- 지역(Region) 및 VPC(Virtual Private Cloud) 종속성: 보안 그룹은 특정 AWS 지역(Region) 및 VPC에 종속
- EC2 인스턴스 외부에서 작동: 트래픽이 보안 그룹에 의해 차단되면, EC2 인스턴스는 해당 트래픽의 존재조차 인지하지 못함.
- 기본 설정
    - 모든 인바운드 트래픽은 기본적으로 차단됩니다.
    - 모든 아웃바운드 트래픽은 기본적으로 허용됩니다.
- 문제 해결 팁
    - 연결 시간 초과(Connection Timeout): 보안 그룹 문제일 가능성이 높습니다. 인바운드 규칙이 올바르게 설정되었는지 확인하세요.
    - 연결 거부됨(Connection Refused): 보안 그룹은 트래픽을 허용했지만, 인스턴스 내의 애플리케이션(서비스)이 실행되고 있지 않거나, 잘못 구성되었을 가능성이 높음

### 개발자가 알아야 할 주요 포트 번호

| 포트 번호 | 프로토콜 | 설명      | 사용 예시            |
| :-------- | :------- | :------- | :---------------- |
| 22        | TCP      | SSH (Secure Shell) | Linux EC2 인스턴스에 원격 접속, SFTP (Secure File Transfer Protocol) |
| 21        | TCP      | FTP (File Transfer Protocol) | 파일 서버에 파일 업로드/다운로드 (보안에 취약)      |
| 80        | TCP      | HTTP (Hypertext Transfer Protocol) | 암호화되지 않은 웹 사이트 접속                   |
| 443       | TCP      | HTTPS (Hypertext Transfer Protocol Secure) | 암호화된 웹 사이트 접속 (오늘날의 표준)             |
| 3389      | TCP      | RDP (Remote Desktop Protocol) | Windows EC2 인스턴스에 원격 데스크톱 접속         |
