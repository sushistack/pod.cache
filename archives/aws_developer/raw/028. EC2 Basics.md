# 028. 🚀 AWS EC2, 클라우드 컴퓨팅의 핵심! 가상 서버 완벽 이해하기

AWS 클라우드 환경에서 웹사이트를 구축하거나 애플리케이션을 배포하려면 가상 서버가 필수적입니다. 이 모든 것의 시작점이 바로 Amazon EC2(Elastic Compute Cloud)입니다. EC2는 AWS가 제공하는 가장 핵심적이고 널리 사용되는 서비스 중 하나로, 클라우드 인프라의 근간을 이룹니다.

이 아티클에서는 EC2가 무엇인지, 어떤 기능들을 제공하는지, 그리고 개발자가 EC2 인스턴스를 어떻게 효율적으로 활용할 수 있는지 자세히 살펴보겠습니다.

### **✨ 3줄 요약**

*   **EC2**는 AWS의 핵심 IaaS(Infrastructure as a Service) 서비스로, 온디맨드로 확장 가능한 가상 서버(인스턴스)를 제공합니다.
*   운영체제, CPU, RAM, 스토리지, 네트워크 등 **인스턴스의 모든 요소를 자유롭게 커스터마이징**할 수 있습니다.
*   **EC2 사용자 데이터** 스크립트를 통해 인스턴스 초기 부팅 시 자동화된 설정이 가능하며, 이는 클라우드 환경의 유연성을 극대화합니다.

## 💡 서론: 클라우드 컴퓨팅의 심장, Amazon EC2

현대의 소프트웨어 개발 및 배포 환경에서 클라우드 컴퓨팅은 더 이상 선택이 아닌 필수가 되었습니다. 그중에서도 Amazon Web Services(AWS)는 압도적인 시장 점유율을 자랑하며 다양한 서비스를 제공하고 있습니다. 이 모든 서비스의 기반 위에 놓인 핵심 서비스 중 하나가 바로 **Amazon EC2(Elastic Compute Cloud)**입니다.

EC2는 "Elastic Compute Cloud"라는 이름에서 알 수 있듯이, 개발자가 필요에 따라 컴퓨팅 용량을 쉽게 확보하고 확장할 수 있도록 돕는 서비스입니다. 이는 클라우드의 가장 기본적인 개념인 "Infrastructure as a Service(IaaS)"를 구현하는 대표적인 예시입니다. EC2를 이해하는 것은 AWS 클라우드 환경에서 작업하는 모든 개발자에게 필수적인 역량이며, 클라우드가 어떻게 작동하는지 근본적으로 이해하는 데 중요한 역할을 합니다.

## 💻 본론: EC2의 구조와 활용 전략

### EC2란 무엇인가? 클라우드 인프라의 시작

Amazon EC2는 AWS 클라우드에서 확장 가능한 컴퓨팅 용량을 제공하는 웹 서비스입니다. 개발자는 EC2를 통해 단 몇 분 만에 가상 서버를 프로비저닝하고 실행할 수 있으며, 필요한 만큼 컴퓨팅 자원을 온디맨드로 대여하여 사용할 수 있습니다. 물리적인 서버를 구매하고 관리하는 대신, 필요한 만큼만 사용하고 비용을 지불하는 클라우드 모델의 핵심을 EC2가 담당합니다.

EC2는 단순히 하나의 서비스가 아닙니다. 이는 여러 구성 요소를 아우르는 포괄적인 개념이며, 고수준에서 다음과 같은 요소들로 구성됩니다.

*   **EC2 인스턴스 (EC2 Instances):** 클라우드 상에서 실행되는 가상 머신(Virtual Machine)입니다. 이 인스턴스를 통해 다양한 애플리케이션을 호스팅할 수 있습니다.
*   **EBS 볼륨 (EBS Volumes):** EC2 인스턴스에 네트워크를 통해 연결되는 영구 블록 스토리지입니다. 가상 드라이브와 유사하며, 인스턴스가 종료되어도 데이터가 유지됩니다.
*   **탄력적 로드 밸런서 (Elastic Load Balancer, ELB):** 여러 EC2 인스턴스에 걸쳐 애플리케이션 트래픽을 자동으로 분산하여 가용성과 확장성을 높입니다.
*   **오토 스케일링 그룹 (Auto Scaling Group, ASG):** 정의된 조건에 따라 EC2 인스턴스의 수를 자동으로 조정하여 애플리케이션의 성능과 비용 효율성을 최적화합니다.

이러한 구성 요소들은 EC2의 강력한 기능과 유연성을 제공하며, 클라우드 환경에서 안정적이고 확장 가능한 아키텍처를 구축하는 데 필수적입니다. 각 요소에 대한 더 깊은 내용은 향후 다루어질 예정입니다.

### 나만의 가상 서버, EC2 인스턴스 커스터마이징

EC2 인스턴스를 생성할 때, 사용자는 자신의 요구사항에 맞춰 가상 서버의 거의 모든 측면을 세밀하게 제어할 수 있습니다. 이는 클라우드의 강력한 커스터마이징 능력을 보여주는 대목입니다.

EC2 인스턴스를 설정할 때 고려해야 할 주요 옵션들은 다음과 같습니다.

*   **운영체제 (Operating System):**
    *   **Linux:** 가장 널리 사용되는 옵션이며, 다양한 배포판(Amazon Linux, Ubuntu, RHEL 등)을 선택할 수 있습니다.
    *   **Windows:** Windows Server 운영체제를 기반으로 한 인스턴스도 제공합니다.
    *   **macOS:** 특정 개발 환경(예: iOS/macOS 앱 개발)을 위해 macOS 인스턴스도 선택 가능합니다.
*   **컴퓨팅 파워 (CPU):** 가상 머신에 할당할 vCPU(가상 CPU)의 개수와 성능을 선택합니다. 인스턴스 유형(Instance Type)에 따라 다양한 CPU 옵션이 제공됩니다.
*   **메모리 (RAM):** 인스턴스에 할당할 RAM의 용량을 선택합니다. 애플리케이션의 메모리 요구사항에 따라 적절한 크기를 선택해야 합니다.
*   **스토리지 공간 (Storage Space):**
    *   **네트워크 연결 스토리지 (Network-attached storage):** 주로 EBS(Elastic Block Store) 볼륨을 사용하며, 인스턴스와 독립적으로 관리됩니다. 필요에 따라 EFS(Elastic File System)와 같은 공유 파일 시스템도 활용할 수 있습니다.
    *   **하드웨어 연결 스토리지 (Hardware-attached storage):** EC2 인스턴스 스토어라고 불리며, 인스턴스의 물리적 호스트에 직접 연결된 임시 스토리지입니다. 고성능이 필요하지만 데이터 지속성이 중요하지 않은 경우에 사용됩니다.
*   **네트워크 유형 (Network Type):** 인스턴스에 연결될 네트워크 인터페이스의 성능과 대역폭을 설정합니다.
*   **방화벽 규칙 (Firewall Rules):** **보안 그룹(Security Group)**을 통해 인스턴스의 인바운드(Inbound) 및 아웃바운드(Outbound) 트래픽을 제어합니다. 특정 포트나 IP 주소로부터의 접근을 허용하거나 차단할 수 있습니다.
*   **초기 설정 스크립트 (Initial Configuration Script):** **EC2 사용자 데이터(User Data)**를 사용하여 인스턴스가 처음 시작될 때 자동으로 실행될 스크립트를 정의합니다.

이처럼 EC2는 사용자가 원하는 대로 가상 서버를 구성하고, 필요에 따라 유연하게 변경할 수 있는 강력한 기능을 제공하여 클라우드 환경의 핵심 가치를 실현합니다.

### EC2 사용자 데이터: 인스턴스 자동 초기화의 마법

EC2 사용자 데이터는 인스턴스가 처음 시작될 때 한 번만 실행되는 스크립트를 정의할 수 있는 기능입니다. 이를 통해 인스턴스 프로비저닝 과정을 자동화하고, 수동 설정에 드는 시간과 노력을 절감할 수 있습니다. 이러한 과정을 **부트스트래핑(Bootstrapping)**이라고 합니다.

**EC2 사용자 데이터의 주요 특징:**

*   **단 한 번 실행:** 인스턴스가 생성되고 첫 부팅을 시작할 때만 실행됩니다. 재부팅 시에는 다시 실행되지 않습니다.
*   **자동화된 초기 설정:** 운영체제 업데이트, 소프트웨어 설치, 설정 파일 다운로드, 서비스 시작 등 다양한 초기 설정 작업을 자동화할 수 있습니다.
*   **루트 권한 실행:** 사용자 데이터 스크립트는 인스턴스 내에서 `root` 사용자의 권한으로 실행되므로, `sudo` 명령어 없이 모든 시스템 작업을 수행할 수 있습니다.

**활용 사례:**

*   웹 서버(Apache, Nginx) 설치 및 설정
*   데이터베이스(MySQL, PostgreSQL) 설치
*   패키지 업데이트 및 보안 패치 적용
*   애플리케이션 코드 다운로드 및 배포
*   시스템 환경 변수 설정

**예시: Apache 웹 서버 설치 스크립트 (Amazon Linux 기준)**

다음은 Amazon Linux 기반 EC2 인스턴스에 Apache 웹 서버를 설치하고 간단한 HTML 페이지를 서빙하는 예시 스크립트입니다.

```bash
#!/bin/bash
sudo yum update -y
sudo yum install -y httpd
sudo systemctl start httpd
sudo systemctl enable httpd
echo "<h1>Hello from AWS EC2!</h1>" | sudo tee /var/www/html/index.html
```

이 스크립트를 EC2 인스턴스 생성 시 사용자 데이터로 입력하면, 인스턴스가 부팅된 후 자동으로 Apache 웹 서버가 설치되고 실행되며, `/var/www/html/index.html` 파일에 "Hello from AWS EC2!"라는 문구가 포함된 웹 페이지가 생성됩니다. 이후 웹 브라우저에서 인스턴스의 퍼블릭 IP 주소로 접속하면 해당 페이지를 확인할 수 있습니다.

사용자 데이터 스크립트를 효과적으로 활용하면, 개발 및 운영의 효율성을 크게 높이고 일관된 환경을 빠르게 구축할 수 있습니다. 다만, 스크립트의 내용이 많아질수록 인스턴스의 초기 부팅 시간이 길어질 수 있으므로, 필요한 최소한의 작업만을 포함하는 것이 좋습니다.

## ✅ 결론: 클라우드 시대의 필수 역량, EC2 마스터하기

지금까지 AWS EC2의 기본 개념부터 주요 구성 요소, 그리고 인스턴스를 세밀하게 커스터마이징하는 방법과 자동 초기화를 위한 EC2 사용자 데이터 스크립트 활용법까지 살펴보았습니다. EC2는 단순히 가상 서버를 제공하는 것을 넘어, 클라우드 환경에서 요구되는 유연성, 확장성, 안정성을 모두 제공하는 AWS의 핵심 서비스입니다.

EC2를 자유자재로 다루는 것은 클라우드 컴퓨팅 환경에서 성공적인 개발 및 운영을 위한 가장 기본적인이자 필수적인 역량입니다. 이 지식을 바탕으로 여러분의 아이디어를 AWS 클라우드 위에서 현실로 만들어 보시길 바랍니다. 다음 아티클에서는 EC2의 실전 활용법에 대해 더 깊이 들어가 보겠습니다.
