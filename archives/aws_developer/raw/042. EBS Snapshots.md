# 042. 💾 EBS 스냅샷 완전 정복: 백업부터 고급 기능까지

AWS 클라우드 환경에서 데이터 가용성과 안정성은 서비스 운영의 핵심 요소입니다. 그중에서도 Amazon Elastic Block Store(EBS) 볼륨의 데이터 백업은 필수적인 관리 작업입니다. 이 아티클은 EBS 스냅샷의 기본 개념부터 데이터 복구 및 마이그레이션, 그리고 비용 효율성과 성능을 극대화하는 고급 기능까지 심층적으로 다룹니다.

## EBS 스냅샷이란 무엇인가?

EBS 스냅샷은 Amazon EBS 볼륨의 특정 시점(point-in-time) 백업입니다. 이는 데이터 손실 위험을 줄이고, 재해 복구(DR) 전략을 구현하며, 개발/테스트 환경 구성을 용이하게 하는 중요한 도구입니다.

### 특정 시점의 데이터 백업

EBS 스냅샷은 볼륨에 있는 모든 데이터를 특정 시점 기준으로 Amazon S3에 저장합니다. 이는 증분(incremental) 방식으로 작동하여, 첫 스냅샷 이후에는 변경된 블록만 저장하므로 효율적입니다.

*   **백업 시 볼륨 분리(detach) 여부**: EBS 스냅샷은 EBS 볼륨을 EC2 인스턴스에서 분리하지 않고도 생성할 수 있습니다. 하지만 일관성 있는 백업을 위해서는 I/O 작업이 일시 중단된 상태(예: 볼륨 분리 또는 파일 시스템 동결)에서 스냅샷을 찍는 것이 권장됩니다.
*   **복구 및 활용**: 스냅샷은 새로운 EBS 볼륨을 생성하거나, 백업된 데이터를 기반으로 다른 EC2 인스턴스를 시작하는 데 활용될 수 있습니다.

### 가용 영역 및 리전 간 데이터 이동

EBS 스냅샷의 강력한 기능 중 하나는 다른 가용 영역(Availability Zone, AZ) 또는 다른 AWS 리전(Region)으로 볼륨을 손쉽게 복사할 수 있다는 점입니다. 이는 재해 복구, 데이터 마이그레이션, 또는 지리적으로 분산된 애플리케이션 배포에 매우 유용합니다.

**가용 영역 간 볼륨 복사 예시:**

1.  **원본 볼륨 스냅샷 생성**: `US-EAST-1A` 가용 영역에 있는 EBS 볼륨의 스냅샷을 생성합니다.
    ```bash
    aws ec2 create-snapshot --volume-id vol-0abcdef1234567890 --description "Snapshot for US-EAST-1A volume"
    ```
2.  **스냅샷 복사**: 생성된 스냅샷을 `US-EAST-1A`에서 `US-EAST-1B`로 복사합니다. AWS 콘솔에서 직접 복사하거나 CLI를 사용할 수 있습니다.
3.  **새 볼륨 생성**: 복사된 스냅샷을 사용하여 `US-EAST-1B` 가용 영역에 새로운 EBS 볼륨을 생성합니다.
    ```bash
    aws ec2 create-volume --snapshot-id snap-0fedcba9876543210 --availability-zone us-east-1b --volume-type gp3
    ```
이러한 과정을 통해 하나의 가용 영역에 있던 EBS 볼륨의 데이터를 다른 가용 영역으로 안전하게 이동시킬 수 있습니다.

## EBS 스냅샷의 핵심 기능들

AWS는 EBS 스냅샷 관리를 위한 다양한 고급 기능을 제공하여, 비용 효율적인 스토리지 운영과 신속한 데이터 복구를 지원합니다.

### EBS 스냅샷 아카이브 (EBS Snapshot Archive)

스냅샷 아카이브는 장기간 보관해야 하지만 자주 접근하지 않는 스냅샷의 비용을 절감하기 위한 기능입니다.

*   **비용 효율성**: 스냅샷을 아카이브 티어로 이동시키면 최대 75%까지 비용을 절감할 수 있습니다.
*   **복원 시간**: 아카이브된 스냅샷을 복원하려면 24시간에서 72시간이 소요됩니다. 따라서 즉각적인 복구가 필요한 경우에는 적합하지 않습니다. 주로 규제 준수, 장기 감사, 또는 예측 가능한 재해 복구 시나리오에 활용됩니다.

### EBS 스냅샷 휴지통 (EBS Snapshot Recycle Bin)

실수로 인한 스냅샷 영구 삭제를 방지하기 위해 EBS 스냅샷 휴지통 기능이 제공됩니다.

*   **데이터 보호**: 스냅샷을 삭제하더라도 즉시 영구 삭제되지 않고 지정된 유지 기간 동안 휴지통에 보관됩니다.
*   **복구 가능성**: 휴지통에 있는 스냅샷은 실수로 삭제된 경우에도 언제든지 복구할 수 있습니다.
*   **유지 기간 설정**: 휴지통에 스냅샷을 보관할 기간을 1일부터 1년까지 설정할 수 있습니다.

### 빠른 스냅샷 복원 (Fast Snapshot Restore - FSR)

일반적으로 스냅샷에서 생성된 EBS 볼륨은 초기 사용 시 데이터에 접근할 때마다 지연 시간이 발생할 수 있습니다. 빠른 스냅샷 복원(FSR)은 이러한 지연 시간을 없애줍니다.

*   **성능 최적화**: FSR은 스냅샷에서 새 볼륨을 생성할 때, 해당 볼륨의 모든 데이터 블록을 미리 초기화하여, 첫 사용 시에도 즉각적인 성능을 제공합니다.
*   **활용 시나리오**: 매우 큰 스냅샷을 기반으로 EBS 볼륨을 빠르게 초기화해야 하거나, 부팅 시간이 중요한 EC2 인스턴스를 신속하게 시작해야 할 때 유용합니다.
*   **비용 고려**: FSR은 매우 유용한 기능이지만, 비용이 고가이므로 필요한 경우에만 신중하게 활성화하고 관리해야 합니다.

### EBS 스냅샷 고급 기능 요약

| 기능                       | 목적           | 장점                                    | 고려사항                                         |
| :------------------------- | :------------- | :-------------------------------------- | :----------------------------------------------- |
| EBS 스냅샷 아카이브        | 비용 절감      | 최대 75% 저렴                           | 복원 시간 24~72시간 소요, 즉시 복원 불가         |
| EBS 스냅샷 휴지통          | 데이터 보호    | 실수로 인한 영구 삭제 방지, 복구 가능   | 유지 기간 설정 (1일~1년)                         |
| 빠른 스냅샷 복원 (FSR)     | 성능 최적화    | 초기 사용 시 지연 시간 없음, 즉시 사용 가능 | 비용 고가, 필요한 경우에만 사용 권장             |

## 결론

Amazon EBS 스냅샷은 단순한 백업 도구를 넘어, 클라우드 환경에서 데이터의 안정성, 가용성, 그리고 효율성을 보장하는 다재다능한 솔루션입니다. 특정 시점 백업을 통한 데이터 복구 능력부터 가용 영역 및 리전 간 데이터 마이그레이션, 그리고 스냅샷 아카이브, 휴지통, 빠른 스냅샷 복원(FSR)과 같은 고급 기능들은 개발자와 IT 관리자가 더욱 견고하고 비용 효율적인 인프라를 구축할 수 있도록 돕습니다.

이러한 EBS 스냅샷 기능을 적절히 활용함으로써, 예측 불가능한 상황에 대비하고 비즈니스 연속성을 확보하며, 클라우드 리소스의 가치를 극대화할 수 있을 것입니다. EBS 스냅샷은 AWS 클라우드 아키텍처의 필수적인 구성 요소이며, 그 잠재력을 이해하고 활용하는 것은 성공적인 클라우드 운영의 초석이 될 것입니다.
