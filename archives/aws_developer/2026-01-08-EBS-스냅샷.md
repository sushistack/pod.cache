### EBS 스냅샷

EBS 스냅샷은 Amazon EBS 볼륨의 특정 시점(point-in-time) 백업입니다. 이는 데이터 손실 위험을 줄이고, 재해 복구(DR) 전략을 구현하며, 개발/테스트 환경 구성을 용이하게 하는 중요한 도구입니다.

#### 특정 시점의 데이터 백업

EBS 스냅샷은 EC2 인스턴스의 EBS 볼륨의 특정 시점(point-in-time)의 데이터를 백업합니다. 이는 EC2 인스턴스가 종료되어도 볼륨의 데이터가 유지됩니다.

- 백업 시 볼륨 분리(detach) 여부: EBS 스냅샷은 EBS 볼륨을 EC2 인스턴스에서 분리하지 않고도 생성할 수 있습니다. 하지만 일관성 있는 백업을 위해서는 I/O 작업이 일시 중단된 상태(예: 볼륨 분리 또는 파일 시스템 동결)에서 스냅샷을 찍는 것이 권장
- 복구 및 활용: 스냅샷은 새로운 EBS 볼륨을 생성하거나, 백업된 데이터를 기반으로 다른 EC2 인스턴스를 시작하는 데 활용

### EBS 스냅샷의 핵심 기능들

| 기능 | 목적 | 장점 | 고려사항 |
| :---- | :------------- | :-------- | :-- |
| EBS 스냅샷 아카이브 | 비용 절감 | 최대 75% 저렴 | 복원 시간 24~72시간 소요, 즉시 복원 불가 |
| EBS 스냅샷 휴지통 | 데이터 보호 | 실수로 인한 영구 삭제 방지, 복구 가능 | 유지 기간 설정 (1일~1년) |
| 빠른 스냅샷 복원 (FSR) | 성능 최적화 | 초기 사용 시 지연 시간 없음, 즉시 사용 가능 | 비용 고가, 필요한 경우에만 사용 권장 |
