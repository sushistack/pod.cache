### AWS 공유 책임 모델이란?

| 책임 영역  | AWS의 책임 (Security *of* the Cloud) | 사용자의 책임 (Security *in* the Cloud) |
| :-------- | :---------- | :-------------------------- |
| **인프라** | 컴퓨팅, 스토리지, 데이터베이스, 네트워킹을 제공하는 물리적 시설 및 하드웨어 | 운영 체제, 네트워크 설정, 방화벽 구성 |
| **데이터** | 없음 | 저장된 데이터의 암호화, 보안 구성, 무결성 관리 |
| **계정 및 접근 관리** | IAM 서비스 자체의 보안 | 사용자, 그룹, 역할 생성 및 정책 관리, MFA 활성화, 접근 키 로테이션 |
| **네트워크 구성**  | 글로벌 네트워크 인프라 보안 | 가상 프라이빗 클라우드(VPC), 보안 그룹, 네트워크 ACL 구성 |
| **애플리케이션**   | 없음 | 고객 애플리케이션의 보안 코드 작성, 패치, 취약점 관리 |
| **운영 체제/런타임** | 관리형 서비스(예: Fargate)의 OS 패치 | EC2 인스턴스의 OS 패치, 미들웨어, 애플리케이션 관리 |
